# Sloth Note 0.8.0

> Voltar preditivo no Android e aviso antes de sair com notas ainda sendo salvas.

Alterado: No Android, o Voltar só é interceptado quando há uma folha, uma tela ou uma gravação pendente para resolver. Na tela inicial sem nada pendente, o sistema pode mostrar a prévia do voltar preditivo antes de sair. Se uma nota ainda estiver sendo salva, o aplicativo avisa antes de fechar; se a gravação falhar, ele continua aberto com a mensagem para tentar de novo.

A prévia do voltar depende da versão do Android e do aparelho. A conferência no aparelho, com gesto e com os três botões, ficou registrada na lista de validação do plano mobile.
