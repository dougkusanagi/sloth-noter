# 0.53.0 — 2026-11-26

### Adicionado

- **Widget Tarefas fixadas no Android (B5)**: adicione o widget **Tarefas fixadas** à tela inicial do celular para ver as tarefas de uma nota fixada, marcar ou desmarcar itens com um toque sem abrir o aplicativo e tocar no título para abrir a nota diretamente. As alterações feitas pelo widget seguem exatamente as mesmas regras de Markdown e datas de conclusão do app, sem conflito quando o app está aberto.
