Alterado: no desktop, Novidades abre uma nota Markdown em uma aba do editor, com toda a largura de leitura disponível. Acesse pelo menu principal ou por Configurações → Novidades. É possível ler, consultar o código e editar a cópia. Ao abrir novamente, a nota é reutilizada se continuar igual ao changelog atual; suas edições são preservadas em uma nota separada.
