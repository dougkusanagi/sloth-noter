Adicionado: O menu [+] agora mostra atalhos para todas as ações. Nos modos Padrão e Código, use Ctrl+Shift+2/3/4 para títulos H2/H3/H4, Ctrl+Shift+5 para tabela, Ctrl+Shift+6 para imagem, Ctrl+Shift+7 para lista numerada e Ctrl+Shift+crase para bloco de código. No macOS, use Cmd+Option+Shift com a mesma tecla. Imagem abre o painel de inserção no Padrão e o seletor de arquivos no Código. As combinações também aparecem nas dicas e em Configurações → Atalhos.
