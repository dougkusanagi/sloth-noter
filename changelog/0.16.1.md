# Sloth Note 0.16.1

Adicionado: Para quem administra o servidor de sincronização, `node server/admin.js` reúne os comandos de administração: `convite` cria um código e já o grava no servidor, `convites` e `contas` listam o que existe, `uso` mostra quanto do limite grátis de imagens do mês foi usado e `revogar <e-mail>` encerra as sessões de uma conta. Use `ajuda` para ver a lista. Ele usa o `server/wrangler.local.toml` quando existe e explica o que fazer quando falta aplicar migrações. O app não muda para quem só usa a sincronização.
