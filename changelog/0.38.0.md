# Sloth Note 0.38.0

> Modo Código no celular acessível também pela folha da nota, com Desfazer, Refazer e esconder teclado na barra de símbolos.

## Adicionado

- No celular, a folha de ações da nota (botão `⋯` no cabeçalho) agora oferece **Modo código** / **Modo visual** para alternar diretamente para o editor Markdown em texto puro, preservando texto, seleção e histórico de desfazer/refazer.
- A barra de símbolos do Modo Código no celular agora inclui os botões **Desfazer**, **Refazer** e **Esconder teclado**, mantendo a preferência de modo salva por nota.
