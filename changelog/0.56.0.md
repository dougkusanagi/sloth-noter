# 0.56.0 — 2026-11-26

### Adicionado

- **Captura por câmera com OCR local no Android (B17)**: quando o aparelho oferece suporte a OCR local, a ação **Capturar texto (OCR)** converte o texto reconhecido em Markdown (**Texto**, **Lista** ou **Tabela**) no próprio aparelho, sem rede, exibindo uma prévia editável antes de inserir na nota.
