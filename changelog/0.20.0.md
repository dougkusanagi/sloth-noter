# Sloth Note 0.20.0

Adicionado: Qualquer nota pode ser um **modelo seu**. Abra a paleta de comandos (Ctrl+Shift+P) ou o menu principal e escolha **Usar esta nota como modelo**. Ela passa a aparecer no começo da lista de **Nova nota a partir de modelo…**, com o rótulo "Seu modelo", e também em **Modelo…** no menu `/`. O arquivo da nota não muda. Para desfazer, use **Remover esta nota dos modelos**. Por enquanto, só no computador dá para marcar a nota; no celular, os modelos marcados já aparecem na lista. Nos modelos, `{{profile}}` mostra o nome do perfil em uso.

Alterado: Blocos de código têm uma borda fina, para não sumirem no tema claro. Parágrafos podem quebrar palavras com hífen quando faltar espaço na linha. Na Leitura, as notas de rodapé ficam um pouco menores e em tom mais suave.
