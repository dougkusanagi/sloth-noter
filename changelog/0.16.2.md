# Sloth Note 0.16.2

Adicionado: Para quem desenvolve o app, `bun run credentials:save` guarda na pasta `.credenciais/` (ignorada pelo git) as chaves e segredos de desenvolvimento (assinatura de atualizações e do APK, chave de recuperação e configuração do servidor), e `bun run credentials:restore` coloca cada um de volta no lugar. O app não muda para quem o usa.
