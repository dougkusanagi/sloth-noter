# Sloth Note 0.5.0

> Copiar, recortar e colar na barra de seleção, que fica mais limpa dentro de blocos de código.

Adicionado: Ao selecionar texto no editor, a barra flutuante agora tem os botões Copiar, Recortar e Colar, antes dos botões de formatação. Dentro de um bloco de código, a barra mostra só esses três botões, porque a formatação Markdown não tem efeito no código.
