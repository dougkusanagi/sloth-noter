# 0.68.0 — 2026-11-27

## Adicionado

- **Espaços compartilhados entre contas (ADR 0054):** agora é possível criar espaços compartilhados e convidar outras contas pelo e-mail, mantendo as notas pessoais separadas e protegidas.
- **Níveis de acesso aplicados no servidor:** cada espaço possui um **Dono**, além de **Editores** (podem ler, criar, editar e apagar notas) e **Leitores** (acesso somente leitura; tentativas de gravação são recusadas pelo servidor).
- **Criptografia de ponta a ponta com par de chaves por conta:** contas novas e existentes recebem um par de chaves ECDH P-256 (chave privada cifrada pela senha) para trocar a chave de cada espaço sem que o servidor leia as notas. Ao remover um membro, a chave do espaço é rotacionada automaticamente para os membros restantes.
- **Gerenciamento no desktop e no celular:** acesse **Configurações → Espaços** no desktop ou **Configurações → Conta e sincronização** no celular para criar espaços, aceitar ou recusar convites, convidar pessoas, alterar níveis de acesso, remover membros, sair ou excluir espaços.
