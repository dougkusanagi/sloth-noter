# Sloth Note 0.5.4

> No celular, o app reabre a última tela mesmo depois de o Android encerrá-lo.

Alterado: No celular, se o Android encerrar o Sloth Note em segundo plano, ao abrir de novo o app volta para a última nota ou tela que você estava vendo, com a mesma posição de rolagem. Só o local da tela é guardado, nunca o texto das notas. Se a nota tiver sido excluída, o app abre a lista. A conferência no aparelho Android real ainda está pendente.
