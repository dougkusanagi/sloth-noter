# 0.69.0 — 2026-11-27

## Adicionado

- **Miniaturas inline de imagens (thumbs):** ao colar ou inserir uma imagem no meio ou no final de uma linha com texto (como uma tarefa ou parágrafo), ela é inserida inline e exibida como uma miniatura compacta alinhada ao texto, tanto no editor Padrão quanto no modo Leitura (desktop e celular).
- **Visualização ampliada (lightbox):** clique ou toque em uma miniatura inline (ou em qualquer imagem da nota) para vê-la em tela cheia; pressione `Esc` ou clique fora para fechar. Imagens inseridas em uma linha vazia continuam aparecendo como bloco inteiro.
