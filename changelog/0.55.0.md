# 0.55.0 — 2026-11-26

### Adicionado

- **IA no aparelho no Android (B7, opcional)**: em aparelhos Android 14+ com modelo local disponível (Gemini Nano / AICore), é possível ativar **IA no aparelho** em **Configurações → Sistema** (desligado por padrão) para resumir ou revisar o texto da nota sem acesso à rede. O resultado sempre aparece como sugestão editável para aceitar ou descartar, e a opção some completamente quando não há modelo local no dispositivo.
