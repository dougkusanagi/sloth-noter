# Sloth Note 0.16.0

Adicionado: Os perfis ganharam uma seção própria, **Configurações › Perfis**. Cada perfil aparece numa linha, com a marca **em uso** no perfil atual. Use **Renomear** para trocar o nome (Enter salva, Esc cancela) e **Novo perfil** para criar outro. Dois perfis não podem ter o mesmo nome.

![Seção Perfis com três perfis, um deles em uso, e os botões Renomear, Usar e Novo perfil](/changelog/perfis-configuracoes.png)

Alterado: A antiga seção **Sincronização** agora se chama **Conta e sincronização**, porque é nela que você cria a conta, entra e sai.

Alterado: A janela de Configurações ficou maior em telas grandes, com mais espaço entre os itens.
