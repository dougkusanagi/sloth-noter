# 0.45.0 — 2026-11-25

## Adicionado

- **Transições suaves ao abrir notas no celular (B1)**: o app passa a usar a View Transitions API ao abrir uma nota a partir da lista, respeitando `prefers-reduced-motion` e com fallback instantâneo sem animação quando não suportado.
- **Háptica com significado no Android (B2)**: vibração curta nativa (`HapticFeedbackConstants`, respeitando a configuração de vibração do sistema) ao cruzar o limite de exclusão no gesto de deslizar da lista de notas e preparada para conclusão de tarefas e navegação por títulos.
