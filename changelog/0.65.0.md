# 0.65.0 — 2026-11-26

### Adicionado

- **Reordenar blocos no celular**: no menu **⋯** da nota, em **Organizar → Reordenar blocos**, cada parágrafo, título, tarefa (`- [ ]`) ou item de lista aparece como um cartão. Arraste o cartão pela alça (⋮⋮) até o novo lugar, ou use as setas para subir e descer um passo. Cada mudança é salva na hora, e **Desfazer** volta a última. Subtarefas acompanham a tarefa de cima; para mover um título com todo o conteúdo dele, use **Mover seção**.
