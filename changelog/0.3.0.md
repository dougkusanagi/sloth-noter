# Sloth Note 0.3.0

## Adicionado

- No editor visual, use Ctrl+D para selecionar uma palavra e adicionar ocorrências à seleção. Digite / em uma linha vazia para buscar e inserir blocos, inclusive links.

![Busca pelo bloco Tabela no menu de inserção](/changelog/buscar-blocos.png)

- Novas notas mostram sugestões para o título e para inserir blocos. Ao abrir uma nota, a lista procura mantê-la visível.
- Ao lado de copiar, alterne entre quebra de linhas e rolagem horizontal nos blocos de código.
- No celular, use o comando `/` e escolha Imagem para inserir um arquivo ou uma imagem por URL na nota.
- No menu de uma imagem, use Encontrar notas para filtrar as notas que a utilizam; remova o filtro na lista de notas.

## Alterado

- Na busca da nota, use as setas para cima e para baixo no campo de busca para ir à ocorrência anterior ou seguinte.
- Imagens em uso podem ser excluídas após confirmação. Elas são removidas das notas, mantendo o texto alternativo.

- O cursor de digitação usa a cor laranja. As sugestões de blocos acompanham o tamanho do texto, o menu abre abaixo da linha e há um espaço visual após o título da nota.

- A sugestão de inserir blocos permanece visível enquanto o título é preenchido e o corpo da nota está vazio.
- A sugestão de blocos fica alinhada ao cursor na linha vazia, inclusive após preencher o título.
