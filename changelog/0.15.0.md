# Sloth Note 0.15.0

Adicionado: A sincronização agora usa uma conta com nome, e-mail e senha. Em **Configurações › Sincronização**, escolha **Criar conta** no primeiro aparelho (com o código de convite que você recebeu de quem administra o servidor) e **Entrar** nos outros. Não é mais preciso digitar endereço do servidor, chave de acesso nem chave de recuperação. As notas continuam cifradas no aparelho: a senha não é enviada ao servidor.

![Formulário Criar conta com nome, e-mail, senha e código de convite](/changelog/conta-sincronizacao.png)

Adicionado: Ao criar a conta, o app mostra uma chave de recuperação opcional. Se você esquecer a senha, use **Entrar › Esqueci a senha** com essa chave para criar uma senha nova sem perder as notas do servidor. Sem a chave, as notas guardadas no servidor não podem ser abertas; as notas dos seus aparelhos continuam salvas.

Alterado: Aparelhos já conectados com a chave de acesso antiga mostram **Conexão antiga** e continuam sincronizando por enquanto. Crie uma conta ou entre na sua conta na mesma tela: as notas do aparelho são enviadas para ela. A chave antiga vai deixar de funcionar quando o servidor for atualizado.

Alterado: O botão **Desligar** virou **Sair da conta**. As notas continuam no aparelho e no servidor.
