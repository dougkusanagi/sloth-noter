# Sloth Note 0.13.1

Alterado: Ao criar uma nota, os campos vazios mostram **“Dê um título à sua ideia”** e **“Sobre o que é esta nota? (opcional)”**, com uma única dica para inserir blocos abaixo da descrição: o botão **+** com **“Digite / para inserir blocos”** no desktop. Clicar em **+** insere o bloco abaixo da descrição, que continua disponível. No app Android a dica não aparece; use a barra de formatação.

![Nota vazia com os convites para escrever o título e a descrição e a dica para inserir blocos](/changelog/dica-insercao-nota-vazia.png)

Corrigido: Novas páginas identificam a segunda linha como descrição opcional. Ao ignorá-la com Enter ou apagar a segunda linha vazia, os textos de ajuda e a dica de blocos com o botão **+** permanecem visíveis.
