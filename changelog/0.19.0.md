# Sloth Note 0.19.0

Adicionado: Os modelos de nota agora também funcionam dentro de uma nota e no celular. No computador, digite **/** numa linha vazia (ou use o botão de inserir) e escolha **Modelo…** para colocar um modelo na nota aberta, sem repetir o título. No celular, o botão de modelo, ao lado de **Nova nota**, cria uma nota a partir de um modelo, e **Inserir → Modelo** coloca o modelo na nota que você edita.

Adicionado: Novo modelo **Quadro de projeto**, com tarefas por seção prontas para o modo Quadro, e duas variáveis nos modelos: `{{weekday}}` (dia da semana) e `{{date+7d}}` (data daqui a alguns dias).
