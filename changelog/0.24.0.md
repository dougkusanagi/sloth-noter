# Sloth Note 0.24.0

Adicionado: **Variável…** no menu de inserir (`/`). Abre uma lista com busca que mostra a prévia do valor: data de hoje, última alteração, palavras, tempo de leitura, progresso das tarefas, dias até uma data e as propriedades da nota. Escolha uma para inserir a variável no cursor; em "Dias até uma data", a data de exemplo (daqui a 7 dias) vem selecionada para você trocar. Por enquanto o item existe só no computador.

![Lista de variáveis com a prévia de cada valor](/changelog/variavel-menu.png)

Corrigido: Blocos de código recolhidos mantêm o contorno completo, e os controles de recolher e quebra de linha continuam visíveis enquanto o ponteiro está sobre o bloco. O botão de quebra de linha indica quando a opção está ativa.

Alterado: no celular, Configurações agora tem seções com título (Aparência, Editor, Dados, Conta e sincronização, Sobre), itens em cartões, valor do tamanho do texto ao lado do título, largura do documento em três botões e a opção "Data ao fechar tarefas".
