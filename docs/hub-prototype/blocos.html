O mesmo trecho no .md 

          

            Ao marcar uma tarefa no resultado, o app altera a linha na nota do projeto, não no hub.
            O bloco só guarda a pergunta.
          

        

      

      

        

          
No .md

          

            Só o bloco ```tasks com a consulta em texto. Os resultados não são
            gravados.
          

        

        

          
Só no app

          
O cálculo dos resultados e o estado recolhido de cada grupo.

        

        

          
No Obsidian

          

            Com o plugin Tasks, o bloco mostra a mesma lista. Sem o plugin, aparece como bloco de
            código legível. Use só um subconjunto da sintaxe dele.

À Fazer.md

          

          
Modelos/Sistema web.md

          

        

      

      

        

          
No .md

          

            O modelo é uma nota em Modelos/ com {{title}} e
            {{date}}. O projeto criado é um .md comum.
          

        

        

          
Só no app

          
Qual pasta guarda os modelos e o último modelo usado.

        

        

          
No Obsidian

          

            O plugin nativo Modelos (Templates) usa os mesmos {{title}} e
            {{date}}: dá para usar a mesma pasta nos dois.
          

        

      

    


    
    

      

        

          

            

            
          

          

            Nota do cliente. O texto é seu; o quadro abaixo é calculado.
          

          

          

            
              

                Projeto
                Status
                Tarefas
                Prazo
              

            
            
          

          

            Na nota do projeto, o campo Cliente é um link: clicar abre esta nota.
          

        

        

          

          

          
Sistema Catálogo.md

          
---
status: Ativo
cliente: "[[Loja Aurora]]"
prazo: 2026-11-20

No .md

          

            A relação é um link numa propriedade (cliente: "[[Loja Aurora]]"). A nota
            do cliente não muda.
          

        

        

          
Só no app

          
As somas (projetos, tarefas abertas, próximo prazo). Nada é copiado para o .md.

        

        

          
No Obsidian

          

            O link aparece em Propriedades e em Menções (backlinks). Um bloco
            base filtrado por cliente lista os projetos, mas sem contar
            tarefas.
          

        

      

    


    
    

      

        

          

          
    
          
    
            
          
    
          
    
            O progresso de cada item soma o das subpáginas, como o hub já faz hoje com os projetos.
          
    
        
    
        
    
          
    
          
    
          
    
            O caminho no topo vem de quem tem link para a nota. Não precisa de pastas nem de um
            campo pai.
          
    
        
    
      
    
      
    
        
    
          
    No .md
    
          
    
            Só ## [[Subpágina]] na nota pai, como no hub atual. Cada subpágina é um .md
            na mesma pasta.
          
    
        
    
        
    
          
    Só no app
    
          
    A árvore, o caminho no topo, o que está recolhido e as somas de progresso.
    
        
    
        
    
          
    No Obsidian
    
          
    Links e Menções normais. A árvore não existe lá, mas cada link leva à subpágina.
