# Política de privacidade do Sloth Note

Última atualização: 5 de novembro de 2026

O Sloth Note é um bloco de notas que funciona no seu dispositivo. Ele não exige conta e não coleta dados pessoais.

## Dados que o app guarda

- Suas notas, pastas, imagens e preferências ficam gravadas apenas no seu dispositivo.
- O app não envia esse conteúdo a nenhum servidor, nem do autor nem de terceiros.
- O app não usa anúncios, telemetria nem ferramentas de análise de uso.

## Conexões com a internet

- A versão da Microsoft Store recebe atualizações pela própria Store, conforme a [política de privacidade da Microsoft](https://privacy.microsoft.com/pt-br/privacystatement).
- As versões baixadas do GitHub consultam as releases do projeto no GitHub para verificar atualizações. Essa consulta não envia suas notas.
- Links que você abre numa nota abrem no seu navegador, sob a política do site visitado.

## Como apagar seus dados

Desinstale o app ou apague as notas e pastas dentro dele. Faça um backup antes, se quiser guardar o conteúdo.
